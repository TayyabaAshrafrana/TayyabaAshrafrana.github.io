# Tayyaba Ashraf — IT Student Portfolio

A responsive, minimal white and light-blue portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `css/style.css` — layout, colors and responsive styles
- `js/script.js` — contact links, footer year and mobile navigation
- `assets/favicon.svg` — browser tab icon

## 1. Personalize before publishing
Open `js/script.js` in a text editor and replace:
- `YOUR_EMAIL@example.com` with your professional email address
- the empty `linkedin` value with your LinkedIn profile URL
- the empty `github` value with your GitHub profile URL (optional)

Example:
```js
const portfolio = {
  email: "yourname@example.com",
  linkedin: "https://www.linkedin.com/in/your-profile/",
  github: "https://github.com/your-username"
};
```

Also review the wording in `index.html`. Keep only skills you can honestly discuss in an interview. The three project cards are clearly marked as planned practice projects: complete them first, then update their status and add links to your actual files or repositories.

## 2. Preview on your computer
1. Extract the ZIP file.
2. Open the `tayyaba_portfolio` folder.
3. Double-click `index.html`. It should open in your browser.
4. For edits, use Visual Studio Code or another text editor. Keep the folder structure unchanged.

The Google Fonts import requires an internet connection; the site still works with fallback fonts if it is unavailable.

## 3. Publish free with GitHub Pages
1. Create or sign in to an account at https://github.com/.
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload the contents of this folder to the repository's root. Make sure `index.html`, `css`, `js` and `assets` are at the top level—not inside another nested folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait a few minutes. Your site address will be `https://YOUR-USERNAME.github.io/`.

GitHub's official guide: https://docs.github.com/en/pages/quickstart

## 4. Before sending the link to an employer
- Replace the email and add LinkedIn/GitHub links.
- Complete the practice projects and link real files/screenshots.
- Add your CV PDF if you want to share one (upload it to the repository and add a link in the page).
- Check the site on mobile and desktop.
- Never publish your home address, ID number, passwords or other private information.

## Important honesty note
This starter portfolio describes you as an IT student and lists beginner-level skills. The project cards are proposed practice projects, not completed client work. Finish each project and retain evidence before describing it as completed.
